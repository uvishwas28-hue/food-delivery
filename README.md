# Food Delivery Project

A React + Vite food delivery dashboard with 20 detailed orders.

## Features

- Dashboard with order stats and recent orders
- Orders list with customer, restaurant, payment, status, and totals
- Order details page with items, delivery, payment, partner, and feedback

## Data

Order data is defined in `src/data/initialOrders.js` and includes **20 orders** with details such as:

- Customer contact info
- Restaurant and cuisine
- Itemized order lines (quantity and price)
- Subtotal, delivery fee, tax, discount, and total
- Payment method, status, and transaction ID
- Order status and timestamps
- Delivery address, partner, and instructions
- Rating and feedback

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.
"# food-delivery"
